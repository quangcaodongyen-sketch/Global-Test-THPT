## 👑 2. HỆ THỐNG QUẢN LÝ TÀI KHOẢN, DÙNG THỬ & VIP

### 2.1. Tài khoản Quản trị Admin
- **Thông tin đăng nhập mặc định:**
  - Tên đăng nhập: `Admin`
  - Mật khẩu: `Admin123@`
- **Quyền Admin:**
  - Sử dụng toàn bộ chức năng của website không giới hạn và vĩnh viễn.
  - Quản lý toàn bộ thành viên: Xem, tìm kiếm, lọc theo trạng thái.
  - Kích hoạt, gia hạn gói VIP 1 năm / 2 năm, khóa hoặc mở khóa tài khoản.
  - Reset mật khẩu cho thành viên.
  - Lưu trữ thông tin tài khoản, lịch sử sử dụng và hồ sơ giáo án tải lên.
  - Thống kê toàn diện: Tổng thành viên, dùng thử, VIP, hết hạn, lượt tạo đề hôm nay & tháng.
  - **Bảo mật:** Mật khẩu được mã hóa SHA-256 kèm chuỗi Salt bảo mật; có chức năng đổi mật khẩu Admin an toàn ngay trên giao diện.
  - **Sao lưu dữ liệu:** Có tính năng **Xuất file JSON sao lưu (Export)** và **Phục hồi từ file JSON (Import)** để Thầy Thành lưu trữ về máy tính.

### 2.2. Tài khoản Thành viên & Cơ chế Dùng thử 5 Lượt
- **Đăng ký tài khoản:**
  - Điền đầy đủ: Họ và tên, Trường/Đơn vị công tác, Số điện thoại, Tên đăng nhập, Mật khẩu, Tỉnh/Thành phố, Môn giảng dạy, Cấp học.
- **Hạn chế 1 thiết bị chỉ được dùng thử 1 lần:**
  - Kết hợp **Device Fingerprint (Canvas + Screen + Timezone)**, Cookie, LocalStorage và Số điện thoại.
  - **Không khóa IP** để giáo viên dùng chung mạng trường học không bị ảnh hưởng.
  - Nếu thiết bị đã từng dùng thử, hệ thống hiển thị thông báo:
    *“Thiết bị này đã được sử dụng lượt dùng thử trước đó. Vui lòng đăng nhập tài khoản đã đăng ký hoặc liên hệ Admin để được hỗ trợ.”*
- **Quyền lợi dùng thử:**
  - Mỗi tài khoản được cấp **5 lượt sử dụng đầy đủ toàn bộ tính năng**.
  - Tự động trừ lượt sau mỗi lần tạo đề thi hoặc tải tài liệu.
  - Hiển thị số lượt dùng thử còn lại: *“Bạn còn 2/5 lượt dùng thử.”*

3. **Bước 3:** Chọn “Create API Key / Tạo API Key”.
4. **Bước 4:** Sao chép mã API Key được cấp.
5. **Bước 5:** Quay lại app → dán API Key vào ô tương ứng.
6. **Bước 6:** Nhấn `[💾 Lưu API Key]` và `[🔍 Kiểm tra API Key]`.
   - Khi kết nối thành công: *“✅ API Key đã được kết nối thành công. Bạn có thể bắt đầu sử dụng ứng dụng.”*
- **Đặc điểm bảo mật:**
  - API Key hiển thị dạng ẩn (`••••••••`) với nút bật/tắt mắt xem.
  - Không hiển thị công khai trên giao diện, không lưu vào mã nguồn hay GitHub.
  - Có sẵn 4 nút bấm: `[🔑 Lấy API Key]`, `[📋 Sao chép hướng dẫn]`, `[💾 Lưu API Key]`, `[🔍 Kiểm tra API Key]`.
